# Plan: News Blogger

## Context

Add a daily news-driven blog post to the auto-blogger. Every day at 10am AEST, the daemon searches Google News RSS for recent articles covering vibe coding, AI UI tools, and AI agent development. It generates an editorial commentary post (not SEO), produces a cover image in a clean editorial style, uploads to S3 pending, and emails a notification. The post goes to `website/content/blog/` and flows through the same S3 → GitHub Actions → deploy pipeline as topic articles.

`importFromS3.ts` and the GitHub workflow already have blog path support (done in a prior session).

---

## Files to Create

### `auto-blogger/src/newsSearch.ts`
Fetches and parses Google News RSS feeds. No new npm dependencies — regex XML parsing following the same pattern as `research.ts`.

- `NEWS_QUERIES` constant: `["vibe coding AI", "AI UI tools", "cursor windsurf AI coding", "AI agent frontend development"]`
- `fetchGoogleNewsRss(query: string): Promise<NewsItem[]>` — GETs `https://news.google.com/rss/search?q={query}&hl=en-AU&gl=AU&ceid=AU:en`, parses `<item>` blocks with regex for `<title>`, `<link>`, `<pubDate>`, `<source>`
- `fetchNewsItems(limit = 6): Promise<NewsItem[]>` — runs all 4 queries via `Promise.allSettled`, dedupes by URL, filters to last 48 hours by `pubDate`, sorts newest-first, enriches top N with `fetchContent()` (same strip-tags pattern as `research.ts`)

Private helpers reused from `research.ts` pattern: `decodeHtmlEntities`, `stripTags`, `fetchHtml`, `fetchContent`.

### `auto-blogger/src/generateNewsArticle.ts`
Two-stage LLM generation (outline → draft) for editorial news commentary. Parallels `generateArticle.ts` but no hub/cluster/faq/diagrams/internal-links.

```typescript
export async function generateNewsArticle(input: {
  items: NewsItem[];
  date: string;
  textProvider: "anthropic" | "openai";
  model: string;
}): Promise<{ post: GeneratedBlogPost; tokenUsage: TokenUsage }>
```

- **Outline schema (Zod):** `{ angle, thesis, sectionHeadings (3–7), slug }`
- **Draft schema (Zod):** `{ title, excerpt, readTime, body, imagePrompt }`
- Tone: editorial commentary for developers following AI tooling space. 600–900 words. Inline links to at least 3 source URLs. No FAQ. No diagrams. `DRAFT_MAX_OUTPUT_TOKENS = 4096`.
- Reuse the same `createTextClient` / provider factory pattern from `generateArticle.ts`.

Restructure `runDaemon()` to two inner `while(true)` functions run via `Promise.all`:

```typescript
async function topicLoop() { /* existing logic, unchanged */ }
async function newsLoop() {
  while (true) {
    const slotMinutes = config.newsCycleHour * 60;
    const waitMinutes = minutesUntilSlot(slotMinutes, new Date(), config.timezone);
    if (waitMinutes > 0) await sleep(waitMinutes * 60 * 1000);
    try { await runNewsCycle(); } catch (e) { console.error("[news] cycle failed:", e); }
    await sleep(msUntilNextWindowStart(slotMinutes, config.timezone));  // reuses existing helper
  }
}

await config.newsCycleEnabled
  ? Promise.all([topicLoop(), newsLoop()])
  : topicLoop();
```
