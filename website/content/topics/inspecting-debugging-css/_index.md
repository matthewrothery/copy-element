    answer: "Authored CSS is what appears in stylesheets. Computed CSS is what the browser applies after cascade, inheritance, and defaults—what you usually need when rebuilding an element."
  - question: "When should I use an inspector extension?"
    answer: "When you need faster iteration or cleaner output for reuse—especially if you are feeding styles into components or AI tools."
