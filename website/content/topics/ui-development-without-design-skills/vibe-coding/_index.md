faq:
  - question: "What is vibe coding exactly?"
    answer: "Vibe coding is a workflow where you build UI by iterating quickly with AI tools and real references rather than designing in Figma first. The goal is to get to something that looks good fast, then refine from there."
  - question: "Is vibe coding only for prototypes?"
    answer: "Not necessarily. Many production applications are built this way - especially in early-stage startups where speed matters more than a formal design system. With the right references and constraints, vibe coding can produce production-quality output."
  - question: "Do I need AI tools to vibe code?"
    answer: "No, but they accelerate the workflow dramatically. Without AI, vibe coding means manually adapting reference components. With AI tools like Cursor and Claude Code, you can describe adaptations and have them applied instantly."
