faq:
  - question: "What is Cursor and how is it different from GitHub Copilot?"
    answer: "Cursor is an AI-native code editor built on VS Code. Unlike Copilot (which works inline in existing editors), Cursor has a Composer mode that accepts large context windows — making it ideal for pasting entire UI components and giving structural instructions."
  - question: "How much HTML context should I give Cursor?"
    answer: "For a single component, paste the full HTML and CSS of the element you want to modify or rebuild. For a page layout, capture the key sections (hero, nav, footer). More specific context produces more accurate output."
  - question: "Can Cursor convert HTML to React components?"
    answer: "Yes. Paste the HTML, ask Cursor to convert it to a React functional component with TypeScript, and it will generate the component, props interface, and CSS-in-JS or module CSS as needed."
