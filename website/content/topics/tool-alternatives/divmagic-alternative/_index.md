faq:
  - question: "What is DivMagic?"
    answer: "DivMagic is a Chrome extension that captures UI components from websites and converts them to Tailwind CSS. It is designed for developers who use Tailwind in their projects."
  - question: "What is the main difference between DivMagic and Element Armory?"
    answer: "DivMagic converts captured UI to Tailwind classes. Element Armory outputs clean computed CSS and raw HTML without a CSS framework assumption - making it framework-agnostic and more flexible for AI workflows."
  - question: "Does Element Armory support Tailwind output?"
    answer: "Not currently. Element Armory focuses on clean HTML and computed CSS output. Tailwind conversion is on the roadmap but not yet available."
