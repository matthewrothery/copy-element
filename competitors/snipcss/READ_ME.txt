New SnipCSS Control 'Change Selection' - allows you to move to parent/child, and select only some elements in container (PRO feature)
-----------------------------------------------------
Pro Feature - "Scope Generic elements to Snipped DOM" works completely different now.  Before it would try to
use the root elements css class... for example a generic "a" tag rule would be changed from/to:
a
.rootcss a
That changed the specificity too much and caused issues with inherited rules.  It gave better results to add a custom class for each
a tag, like .snip-a and add that to all "a" elements in the snipped html.  It adds more clutter to the html, but if
scoping is turned on it's assumed you'll want to drop the snippet somewhere without affecting the rest of the page you're dropping it in.
Hopefully doing it this way keeps the snippet looking close to the original while also keeping rules scoped to its own dom.
