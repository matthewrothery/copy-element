SnipCSS has been updated and is now using Manifest V3.

Manifest V3 uses different permission settings so if anything isn't working as expected please contact support@snipcss.com.

To get started just go to a website, click the SnipCSS extension icon. The page will reload and it will say SnipCSS is debugging the page. (Do NOT click Cancel)

While hovering over items it will show the current selection. Click a portion of the webpage you want to extract. A button will appear to Snip the CSS, or you can click "Run Snipper" in the floating control panel.

After the Snip Kiwi extracts the HTML/CSS/Images, the Snip will be available in the dropdown above.

Tutorial

1. Go to the website that has the HTML element you wish to snip. Click the SnipCSS extension icon. If you do not see the icon, click the puzzle icon, then click the SnipCSS icon in there

2. It will say SnipCSS is debugging the page, do NOT cancel it. Hovering over elements will now show the element you are targeting if you were to snip it. Click the element you want and the "Run Snip CSS" button should appear. If your element was too specific you can click up icon to go to the parent element. When you have the correct element click "Run Snip CSS."

3. The Kiwi will come on the page and start extracting the styles from the DOM subtree of elements that you wanted to snip. It may take a few seconds, or over a minute depending on the number of styles to process and the selected element. Once done the options page will load with your snippet.
